## How to Run Locally

1. Download or clone this repository.
2. Open index.html in any modern browser.
3. Use the navigation bar to move between tasks.

## How to Publish on GitHub Pages

1. Create a new repository on GitHub.
2. Upload all files (make sure index.html is in the root).
3. Go to Settings, then Pages.
4. Under Source, select the main branch and the root folder.
5. Save. The site will be available at https://your-username.github.io/your-repo-name
